# Bài thực hành phối màu đơn tông (Monochromatic)

Bài tập thực hành HTML/CSS gồm **2 phiên bản**:

- `index.html`: giao diện **xanh dương**, sử dụng đúng mã màu trong yêu cầu bài: #00ADEE (chủ đạo/ON SALE), #00B2EF (PREVIEW), #00BFF2 (thanh điều hướng/nền), #8DD7F7 (nền nội dung), #C6E9FA (footer).
- `tim/index.html`: giao diện **tím đơn tông** để đáp ứng bước 8, dùng bảng màu tím cùng cấu trúc.
- `styles.css`: toàn bộ phần trình bày.
- `app.js`: popup xem nhanh sản phẩm.
- `assets/`: minh họa SVG, chạy ngoại tuyến, không cần cài thư viện.

## Cách chạy

Mở `index.html` bằng trình duyệt hoặc dùng VS Code > Live Server. Nhấn **Đổi sang màu tím** để xem bản 2.

## Cách nộp Github

Tạo repository PUBLIC mới (ví dụ: `thuc-hanh-phoi-mau-don-tong`), upload toàn bộ các file/thư mục này, commit; sau đó nộp đường dẫn repo. Có thể bật Pages tại Settings → Pages → Deploy from a branch → main / (root).

## Lưu ý nguồn mã

Bài tập cung cấp `Pra.zip` của CodeGym. Do kho lưu trữ chỉ cung cấp ZIP nhị phân không đọc được trực tiếp qua công cụ đang sử dụng, bản nộp này là **trang minh họa được dựng lại theo yêu cầu màu sắc và các vùng ON SALE / PREVIEW**, không phải chỉnh trực tiếp từ mã nguồn gốc `Pra.zip`. Nếu giảng viên bắt buộc giữ nguyên cấu trúc và tài nguyên mẫu, hãy cung cấp file `Pra.zip` để sửa trực tiếp.
